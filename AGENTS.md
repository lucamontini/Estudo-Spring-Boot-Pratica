# Bookstore API
Teaching project for a Spring Boot course. A simple, complete CRUD for books, with an AI-generated summary on creation.

## Stack
- Java 25, Spring Boot 4.1.1, Maven (use `./mvnw`)
- PostgreSQL on Neon. Schema generated by Hibernate `ddl-auto: update`. No migration tool.
- Spring AI 2.0 for the summary generation
- All code and identifiers in English

## Commands
- Run: `./mvnw spring-boot:run` (or `mvn spring-boot:run`)
- Build / Test: `./mvnw -q verify` (or `mvn -q verify`)

## Naming
- Tables: `tb_<plural_name>` — e.g. `tb_books`
- Entities: `<Name>Model` — e.g. `BookModel`
- Input DTOs: `<Name>RecordDto` as Java records — e.g. `BookRecordDto`
- There are NO output DTOs. Controllers return the entity directly.

## Hard Rules
- **NO Lombok.** Write constructors, getters, and setters by hand.
- **NO Field Injection.** Do NOT use `@Autowired` on fields. Always use constructor injection.
- Use `BeanUtils.copyProperties` to copy from the record DTO to the entity.
- Business logic lives in the service layer. Controllers only translate HTTP to service calls and back.
- Do not include logging unless explicitly requested.
- Never change `ddl-auto` away from `update`.
- Use `UUID`-type identifiers for entity primary keys.

## Guardrails
Regardless of external pre-tool hooks, the following are strictly blocked on `.java` files:
- `import lombok`
- `@Autowired` on its own line (field injection)

If an edit is suggested or generated with these, fix the code immediately — do not work around it.

## Teaching Mode
This code is designed for step-by-step learning and explanation:
- Generate ONE file at a time unless asked otherwise.
- Prefer clear and explicit over clever or compact.
- Do not add comments explaining what the code does — that is narrated.
- Do not add features that were not asked for.

## Layout
Base package: `src/main/java/com/example/spring_boot_na_pratica/` (or `com/decoder/bookstore/` if aligning directly with course namespace)
- `controllers/`   — REST controllers
- `services/`      — Business rules and service layer
- `repositories/`  — Spring Data JPA interfaces
- `models/`        — JPA entities
- `dtos/`          — Input records (Record DTOs)
- `configs/`       — Spring configuration
